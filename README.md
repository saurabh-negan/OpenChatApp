# Open Chat 💬⚡

A real-time chat application built with the MERN stack and Socket.IO.  
Open Chat allows users to join rooms, send instant messages, and experience live chat updates without refreshing the page.  

## Features
- 💬 Real-time messaging powered by WebSockets (Socket.IO)
- 👥 User authentication and room management
- 🔔 Instant updates for new messages and participants
- 📱 Responsive and modern UI with React + Tailwind CSS
- 🗂️ Clean project structure with frontend and backend separation

## Tech Stack
- **Frontend:** React + Zustand + Tailwind CSS
- **Backend:** Node.js + Express
- **Real-time:** Socket.IO (WebSockets)
- **Database:** MongoDB.
